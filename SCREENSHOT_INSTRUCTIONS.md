# Taking a Screenshot for the Repository

To add a screenshot of your Todo App to the repository:

1. Open the app in your browser at http://localhost:5000 (or your deployment URL)
2. Use your operating system's screenshot tool:
   - **Windows**: Press `Windows+Shift+S` to open the snipping tool
   - **macOS**: Press `Command+Shift+4` to take a screenshot of a selected area
   - **Linux**: Use a tool like `gnome-screenshot` or `flameshot`

3. Save the screenshot as `screenshot.png` in the root directory of the project

4. The screenshot will then be displayed in the README.md file when viewed on GitHub

## Tips for Taking a Good Screenshot

- Make sure the app is in a clean state with some sample tasks
- Include examples of tasks with different priorities and completion states
- If possible, show both light and dark theme versions side by side
- Ensure the UI is not cluttered with debug information
- Use a reasonable window size that shows the responsive design
